# 常規的大模型訓練方案
pretrain -> sft -> rl

# DeepSeek-R1-Zero
pretrain -> rl

缺陷：中英文混合、格式混亂

# DeepSeek-R1
pretrain -> sft一階段 -> rl一階段 -> sft二階段 -> rl二階段

## sft一階段（冷啟動）

目的：引入數千條高品質長推理鏈資料對基礎模型微調，強制規範輸出格式（如\<think>推理過程\</think>），提升可讀性。\
資料來源：收集DeepSeek-R1-Zero的輸出結果，以可讀的格式呈現，最後透過人工標註者進行後處理以優化結果

## rl一階段（推理導向的rl）

rl方法：GRPO\
獎勵模型：基於規則的獎勵（答案準確性和語言一致性），針對程式碼、數學、編程等有固定答案的任務設計獎勵函數。

## sft二階段

資料來源：推理資料和非推理資料合併

推理資料：rl一階段checkpoint輸出資料（60萬）。rl一階段，僅納入了可以基於規則的獎勵進行評估的資料。在sft二階段，透過引入額外的資料來擴展資料集，其中一些資料透過將真實答案和模型預測輸入DeepSeek-V3進行判斷，使用生成式獎勵模型。此外，由於模型輸出有時會顯得混亂且難以閱讀，過濾掉了包含混合語言、長段落和程式碼塊的推理鏈。對於每個提示，採樣多個回答，僅保留正確的回答。收集了大約60萬個與推理相關的訓練樣本。

非推理資料：如寫作、事實問答、自我認知和翻譯等，重用DeepSeek-V3監督微調資料集的部分內容。收集了大約20萬個與推理無關的訓練樣本。

## rl二階段(通用對齊的rl)

通用對齊RL（RLHF）：融入人類偏好獎勵模型（Helpfulness & Harmlessness），確保模型在開放域任務中的安全性與實用性。
