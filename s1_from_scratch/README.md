# S1模型

## 概述
以**不足50美元的雲計算成本**完成訓練，在數學推理和程式碼生成等任務中展現出與OpenAI的o1、DeepSeek的R1等頂尖模型相媲美的效能。

---

## 實作流程
### 資料來源
16 個不同的來源收集59029個問題，主要包括數學問題。
透過Google Gemini Flash Thinking API生成推理軌跡，得到三元組（問題，推理，答案）（蒸餾Gemini，之後使用DeepSeek r1重新生成軌跡，效能進一步提升）
### 資料處理
1、品質過濾：剔除呼叫API出錯的樣本，保留54116個，剔除格式有問題的樣本，保留51,581個\
2、 研究人員篩選出高品質且無需進一步篩選的資料共384個樣本作為最終1,000 個樣本的一部分\
3、難度過濾：Qwen2.5-7B-Instruct 和 Qwen2.5-32B-Instruct生成問題答案，Claude 3.5 Sonnet評估正確性，去除模型回答正確和推理軌跡短的樣本，保留24496個\
4、Claude 3.5 Sonnet將資料按數學主題分類（MSC），覆蓋50個領域。隨機選擇一個領域，按照推理鏈長短進行排序，優先選擇長度較長的，不斷迭代，直到得到1000個樣本（加上之前的384個）
### 微調
使用1000條資料微調Qwen2.5-32B-Instruct
### 測試時擴展
**預算強制**控制模型思考過程，進一步提升模型的效能
